# 🔐 Cybersecurity Labs

A collection of hands-on cybersecurity projects, SOC investigations, threat hunting exercises, and TryHackMe writeups. This repository documents my practical journey across blue-team, red-team, and security automation work.

## 📁 Contents
- **TryHackMe Labs** — walkthroughs, notes, and attack/defense exercises  
- **Blue Team** — SIEM investigations, log analysis, detection engineering  
- **Red Team** — enumeration, exploitation, privilege escalation  
- **Threat Hunting** — hypotheses, hunts, and findings  
- **Automation Scripts** — Bash, PowerShell, Python tooling  
- **Incident Response** — IR workflows, reports, and playbooks

Splunk • ELK • Suricata • Wireshark • Zeek • Sysmon  
Python • Bash • PowerShell  
MITRE ATT&CK • Threat Intelligence • DFIR

## 🎯 Purpose
To demonstrate real-world cybersecurity skills through structured, practical, and repeatable labs.
